# Wine Quality Prediction

## Objective
Build and compare multiple machine learning classifiers that predict wine quality from its physicochemical properties, and recommend the best candidate for deployment.

## Dataset
`WineQT.csv` — physicochemical measurements (fixed acidity, volatile acidity, citric acid, residual sugar, chlorides, free/total sulfur dioxide, density, pH, sulphates, alcohol) with an original quality score from 3–8.

## Process
1. **EDA** — inspected the original quality distribution, plotted every chemical feature's distribution, and built a correlation heatmap.
2. **Class imbalance check** — the raw 3–8 quality scale was heavily skewed toward scores 5 and 6.
3. **Feature engineering** — regrouped quality into three balanced-enough classes: **Low**, **Medium**, **High** (522 / 462 / 159 wines respectively), reducing sparsity while keeping more signal than a binary good/bad split.
4. **Train/test split** — 80/20 split, stratified on the new `quality_group` target to preserve class proportions.
5. **Model training** — trained three classifiers with balanced class weights: **Random Forest**, **SGD** (with feature scaling), and **SVC** (with feature scaling).
6. **Evaluation** — accuracy, classification report (precision/recall/F1), and confusion matrices for each model; macro F1 was tracked given the class imbalance.
7. **Feature importance** — extracted and visualized Random Forest's feature importances to see which chemical properties mattered most.

## Results
| Model | Accuracy | Macro F1 |
|---|---|---|
| **Random Forest** | ≈69.00% | ≈68.58% |
| SVC | ≈62.88% | — |
| SGD | ≈53.28% | — |

**Model ranking:** Random Forest > SVC > SGD

## Recommendation
Random Forest is the strongest candidate: highest accuracy and macro F1, reasonable performance across all three quality groups, built-in feature importance for interpretability, and no scaling requirement. It's treated here as a **portfolio-level model** — before any real-world use it would need evaluation on additional unseen data, cross-validation, and further hyperparameter tuning.
