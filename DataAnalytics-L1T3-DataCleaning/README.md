# Titanic Dataset – Data Cleaning Project

## Objective
Clean and prepare the Titanic dataset for further analysis by identifying and handling missing values, duplicate records, inconsistent formatting, outliers, and incorrect data types.

## Dataset
Titanic-Dataset.csv — 891 rows, 12 columns (passenger-level survival data).

## Process
1. **Data quality report** — profiled missing values, duplicates, and current data types for every column before touching the data.
2. **Missing data handling**
   - `Age` (177 missing) → filled with the median, since age is numerical and the median resists outlier skew.
   - `Cabin` (687 missing) → filled with `"unknown"` rather than dropped, to preserve passenger records.
   - `Embarked` (2 missing) → filled with the mode.
3. **Duplicate check** — no duplicate rows were found, so all 891 records were retained.
4. **Standardisation** — trimmed whitespace on text fields; normalised `Sex` to `Male`/`Female` and `Embarked` to uppercase codes (S, C, Q).
5. **Outlier detection** — used the IQR method on Age, SibSp, Parch, and Fare. Flagged values were reviewed and retained, since they represented plausible fares/family sizes rather than data-entry errors.
6. **Data type correction** — cast identifiers/text to `string`, categorical fields to `category`, and numeric fields to appropriate int/float types.
7. **Validation & export** — reran the full quality check after cleaning and saved the result as `Titanic_Cleaned.csv`, leaving the original file untouched.
